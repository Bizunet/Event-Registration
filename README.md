# DDUECSF Thanksgiving Program Registration

A mobile-responsive event registration, digital ticket, and organizer guest roster built with Next.js, PostgreSQL, Prisma, Tailwind CSS, Lucide, and QRCode React.

## Setup

1. Install Node.js 20+ and PostgreSQL.
2. Copy `.env.example` to `.env` and set `DATABASE_URL`, `ADMIN_PIN`, `ADMIN_SESSION_SECRET` (at least 32 characters), `BLOB_READ_WRITE_TOKEN`, and the public app URL. Create a **private** Vercel Blob store for payment receipts.
3. Install dependencies and initialize the database:

   ```sh
   npm install
   npm run db:push
   npm run dev
   ```

Visit `http://localhost:3000`. Set a long, unique organizer PIN before exposing `/admin/guests`; use HTTPS in production.

## Routes

- `/` — event landing page and attendee registration
- `/ticket/[ticketId]` — attendee digital pass with a verification QR and PNG download
- `/admin/guests` — PIN-protected searchable guest list, CSV export, and live QR check-in
- `/api/attendees` — validated registration endpoint; unique email addresses are enforced by PostgreSQL
- `/api/payment-receipts` — validates and privately uploads PNG, JPEG, or WebP payment receipts to Vercel Blob
- `/api/admin/receipts/[attendeeId]` — organizer-authenticated private receipt image proxy
- `/api/admin/check-in` — organizer-authenticated QR ticket check-in endpoint
- `/api/ticket/[ticketId]` — public ticket verification details

Tickets are UUIDs generated by PostgreSQL/Prisma. Check-in timestamps and optional payment receipt URLs are stored on each attendee. Receipt images are stored as private blobs and served only through an organizer-authenticated endpoint. After pulling schema changes, run `npm run db:push` to add the check-in and receipt columns. Camera access requires HTTPS in production; localhost is supported for development.
